B is time-aligned to A by cross-correlation, polarity-checked, then gain-matched by integrated loudness (ITU-R BS.1770). Residual = B − A. ESR is NAM's own training error metric (Σ(B−A)² / ΣA²).

Each trial plays a random section of one of the two, hidden. You say which. No feedback until the end, then score and p-value.

Space play/pause · 1/2/3 or A/B/X select source (4/D = difference signal in Explore) · [ = it was A · ] = it was B.
Level matching uses integrated LUFS so the comparison tests tone, not volume (0.1 dB mismatches are reliably heard as "better"). Alignment is to the nearest sample; sub-sample error limits how deep the null can go at high frequencies, so treat the residual number as an upper bound on the real difference. A single input only tests the model for that playing; dynamic/nonlinear behaviour on other material can differ.
